# Simple Omelette Recipe Page

## About the Project

This project is based on the Recipe Page challenge from Frontend Mentor. I recreated the provided design using HTML and CSS as part of my coding practice.

The goal was to practice structuring a webpage with HTML and using CSS to style the layout, colors, fonts, and spacing.


## What the Page Includes
- An image of the omelette
- A short recipe description
- Preparation and cooking times
- A list of ingredients
- Step-by-step cooking instructions
- Nutritional information

## Technologies Used
- **HTML** – To structure and organize the webpage.
- **CSS** – To style the layout, colors, fonts, and spacing.
- **Google Fonts** – To import custom fonts.

## HTML Skills Practiced
- Headings and paragraphs
- Images and links
- Ordered and unordered lists
- `div` and `section` elements
- Classes and semantic HTML elements
- Horizontal rules

## CSS Skills Practiced
- Background and text colors
- Font families and font sizes
- Margins and padding
- Borders and rounded corners
- Flexbox for the nutrition section
- CSS selectors and pseudo-elements
- Image sizing and link styling

## What I Learned
This project helped me practice turning a provided design into a webpage using HTML and CSS.

I gained more experience organizing content, styling different sections, adjusting spacing, and using Flexbox to align information.
